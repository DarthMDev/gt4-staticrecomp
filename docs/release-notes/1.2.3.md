# GT4Recomp 1.2.3

**A hotfix release: the game no longer crashes at start for players who were not on GSdx, texture packs go straight
into the Textures folder, and the installer makes a desktop shortcut.** You need your own disc image of the game.

## Install or update

- Update from 1.2.1 or 1.2.2: accept the update in the launcher and say yes to the one administrator prompt. The
  update is silent, and the launcher starts again by itself when it is done.
- Update from 1.2.0 or 1.1.0: accept the update in the launcher; Windows shows the administrator prompt and the setup
  pages once. If nothing happens after the download, close the launcher and run **GT4Recomp-Setup-1.2.3.exe**
  yourself. The first start moves your files to the 1.2.1 layout (see the [1.2.1 notes](1.2.1.md)).
- Update from 1.0.0: run the installer (the 1.0.0 update button does not work).
- New install: download **GT4Recomp-Setup-1.2.3.exe** and run it.

## Fixes

- **The game crashed at start with CoreGS 1.1** in 1.2.2 (chosen in Settings, or used when GSdx could not start).
  The cause is fixed in the game, and the launcher no longer uses CoreGS 1.1 at all (below).

## Changes

- **GSdx is the only renderer.** CoreGS 1.1 is removed from the launcher; Settings shows GSdx and **CoreGS 2.0
  (coming soon)**, which is our own renderer in development. If you had chosen CoreGS 1.1, the launcher switches you
  to GSdx. If GSdx cannot be installed or stops, Play shows a clear message with what to do and where the logs are,
  instead of falling back to another renderer. The settings that only CoreGS 1.1 used are gone.
- **Custom textures straight in the Textures folder.** GSdx 1.2.1 (installed by the launcher automatically) reads
  texture packs from `data\Textures` itself, at any folder depth: paste the pack folder straight into `Textures`
  (Settings > Graphics > **Open textures folder**). The launcher no longer creates a `replacements` folder, and moves
  the contents of an existing `Textures\replacements` up into `Textures` once (nothing is overwritten: a name that
  already exists stays where it is).
- **Desktop shortcut.** The installer's last page has **Create a desktop shortcut**, ticked by default; it makes
  **Gran Turismo 4** on the desktop of every user of the PC. Updates keep your choice: a shortcut you asked for is
  made again if it is missing, and one you declined is not created. Installs from before 1.2.3 get the shortcut at
  this update.

## Unchanged

- The game is the 1.2.2 game (same picture and performance) with the crash fix.
- Settings, controls, saves and replays are kept.

## Known issues

- Every known issue of 1.2.2 is still open.
