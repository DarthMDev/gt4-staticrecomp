# GT4Recomp 1.2.0 (draft)

**Custom textures, the GSdx renderer choice, and a desktop-following resolution.** You need your own disc image of the game.

## Install or update

- New install: download **GT4Recomp-Setup-1.2.0.exe** and run it (per-user, no administrator rights). Setup asks which
  graphics renderer to use: **GSdx** (recommended) or **CoreGS 1.1** (built in, no download).
- Update from 1.1.0: run the new installer over the old one, or use the launcher's update. Your settings are kept; a
  copy of the old settings file is made first.
- The launcher needs **gt4-gs 1.2.0** for GSdx. An older gt4-gs is replaced at the next start.

## What's new

- **GSdx renderer choice.** The renderer formerly called "PCSX2 GS" is named **GSdx** everywhere in the launcher. Setup
  asks once which renderer to use; GSdx is preselected and recommended, CoreGS 1.1 needs no download.
- **Switch to GSdx any time.** Choosing GSdx in Settings > Graphics > Renderer installs it at once when it is missing.
  The progress shows under the Renderer row ("Downloading GSdx…", "Installing…"), then "GSdx installed successfully".
  If the install fails, a clear message says why and CoreGS 1.1 stays selected; the game keeps working.
- **Custom textures.** Put a texture pack's `replacements` folder into `Documents\Gran Turismo 4\Textures`. Settings >
  Graphics > **Load custom textures** is on by default; with an empty folder nothing changes. **Open textures folder**
  is next to it. **Precache custom textures** (Advanced, off by default) loads the whole pack at start. The pack is only
  read; texture dumps are never written.
- **Monitor names.** The Monitor row shows the monitor's name ("DELL U3419W"). Two monitors with the same name are told
  apart as "DELL U3419W" and "DELL U3419W 2".
- **Resolution follows the desktop.** The default Resolution is the monitor's desktop resolution, read again at every
  start and at Play. If you change the desktop resolution (for example with AMD VSR), the game follows it. A size you
  picked yourself stays, unless the monitor no longer has that mode; then the game plays at the desktop mode and the
  log says so.
- **Every gt4-gs option is available.** Blending accuracy (minimum to maximum), deinterlacing, the Vulkan, D3D11 and D3D12
  renderers, hardware readbacks, CAS sharpening, texture filtering, anisotropic filtering, trilinear filtering, dithering,
  texture preloading, shade boost, TV shaders, FMV aspect, anti-aliasing and more; nothing is marked "Coming soon" any
  more. Left out on purpose: the PCSX2 on-screen display positions (GT4 has its own overlay), the GPU name, and
  diagnostics knobs.
- **2-row crop at the bottom** of the picture (gt4-gs 1.2.0; the right stays 1).
- **Black start.** The window is black from its first frame (it was white before the Sony logo).

## Known issues

- Texture packs are not checked against every texture in the game; a pack with another file naming is ignored.
- The D3D11 and D3D12 renderers start on this build but have not been checked on screen; Vulkan stays the default.
- Split screen and photo mode have had little testing at ultrawide ratios (they stay 16:9, pillarboxed).
- Menus are still interlaced at 480i; progressive menus come in a later update.
- A Resolution saved by 1.1.0 next to the Monitor "primary" cannot be recognised as "desktop" (no desktop size is
  recorded there); choose Desktop once in Settings to fix it.
