# GT4Recomp 1.2.0 (draft)

**Custom textures.** Put a texture pack in your own folder and the game uses it. You need your own disc image of the game.

## Install or update

- New install: download **GT4Recomp-Setup-1.2.0.exe** and run it (per-user, no administrator rights).
- Update from 1.1.0: run the new installer over the old one, or use the launcher's update.
- The launcher now needs **gt4-gs 1.2.0**. An older gt4-gs is replaced at the next start.

## What's new

- **Custom textures.** Drop a texture pack's `replacements` folder into `Documents\Gran Turismo 4\Textures`
  (the launcher makes the folders). Settings > Graphics > **Load custom textures** is on by default; with an empty folder
  nothing changes. **Open textures folder** is next to it.
- **Precache custom textures** (Settings > Graphics > Advanced, off by default) loads the whole pack when the game starts:
  more memory, no loading during play.
- The pack is only read: the launcher and gt4-gs never write texture dumps.
- **gt4-gs 1.2.0**: the bottom edge crop is two pixels now (one at the right, as before), so the last line of the picture
  no longer shows at the bottom edge.
- **Black start.** The window is black from its first frame (it was white before the Sony logo).

## Known issues

- Texture packs are not checked against every texture in the game; a pack that uses a different file naming is ignored.
- Split screen and photo mode have had little testing at ultrawide ratios (they stay 16:9, pillarboxed).
- Menus are still interlaced at 480i; progressive menus come in a later update.
