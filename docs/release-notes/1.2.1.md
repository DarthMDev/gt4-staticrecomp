# GT4Recomp 1.2.1

**A per-machine install, with the game data beside the program and your saves in AppData.** You need your own disc
image of the game.

## Install or update

- New install: download **GT4Recomp-Setup-1.2.1.exe** and run it. Windows asks for administrator rights: GT4Recomp now
  installs for every user of the PC, by default in `C:\Program Files\GT4Recomp`. You can pick any other folder or drive
  on the folder page.
- Update from 1.2.0 or 1.1.0: accept the update in the launcher. Windows shows the administrator prompt; say yes.
  This update still shows the setup pages once. If nothing happens after the download, close the launcher and run
  **GT4Recomp-Setup-1.2.1.exe** yourself.
- Update from 1.0.0: run the installer (the 1.0.0 update button does not work).
- Updates from 1.2.1 on are silent: accept the update in the launcher, say yes to the one administrator prompt, and
  the launcher starts again by itself when the update is done.
- Reinstall into another folder or drive: run the setup and pick the folder. The old program files are removed (its
  `data` folder stays), and the launcher moves the old large data (disc copy, prepared game files, gs, runtime card,
  sessions, logs, textures) into the new folder's `data` at its first start, with the same checks as the 1.2.0 move.
  Your settings and saves are in AppData and are not affected.
- The setup removes the old per-user program files (`%LOCALAPPDATA%\Programs\GT4Recomp`), their Start-menu shortcuts
  and their uninstall entry. It never touches your data.

## Where your files are now

| What | 1.2.0 | 1.2.1 |
|---|---|---|
| Program | `%LOCALAPPDATA%\Programs\GT4Recomp` | `C:\Program Files\GT4Recomp` (or the folder you chose) |
| Disc image copy, prepared game files | `%LOCALAPPDATA%\GT4Recomp\disc`, `\prepared` | `<install>\data\disc`, `\prepared` |
| GSdx (gt4-gs) versions and caches | `%LOCALAPPDATA%\GT4Recomp\gs` | `<install>\data\gs` |
| Runtime card, sessions, logs | `%LOCALAPPDATA%\GT4Recomp\runtime`, `\sessions`, `\logs` | `<install>\data\...` (1.2.0 logs in `data\logs\from-1.2.0`) |
| Custom textures | `Documents\Gran Turismo 4\Textures` | `<install>\data\Textures` |
| Settings | `%LOCALAPPDATA%\GT4Recomp\config` | `%APPDATA%\GT4Recomp\config` |
| Controls | `%LOCALAPPDATA%\GT4Recomp\controls.toml` | `%APPDATA%\GT4Recomp\controls.toml` |
| Saves and replays | `Documents\Gran Turismo 4\Saves`, `\Replays` | `%APPDATA%\GT4Recomp\Saves`, `\Replays` |
| Card backups | `%LOCALAPPDATA%\GT4Recomp\library\backups` | `%APPDATA%\GT4Recomp\backups` |

The launcher moves everything at its first start, running as you:

- Your settings, controls, saves and replays are **copied** and checked byte for byte. Then
  `Documents\Gran Turismo 4` is renamed to **`Gran Turismo 4 (moved to AppData)`**, with a `README.txt` that says where
  the files went. Nothing is deleted: once your saves show in the launcher, you may delete that folder yourself.
- The game files (about 5 GB) are **moved**. On the same drive this is instant. To another drive they are copied with a
  progress line in the launcher window, checked (size and SHA-256, and the disc image against its known hash), and only
  then removed from the old place. Play waits until the move has finished.
- If something cannot be moved (a file in use, OneDrive files that are only online, a full disk), the old place stays in
  use and the launcher tries again at the next start. Nothing is overwritten: if the new place already has a file, both
  are kept (a save goes to the next free slot).
- Nothing moves while the game runs.

## Portable

The whole `GT4Recomp` folder can be copied to another drive or another PC and started from there. The launcher finds
its data in the `data` folder next to `GT4Recomp.exe`; on a new PC it starts with default settings and uses the disc
copy and GSdx it finds there. A copy placed in a folder you cannot write (such as Program Files on another PC, without
the installer) still works: the launcher reads its data and writes new files to `%LOCALAPPDATA%\GT4Recomp`.

## Uninstall

Uninstalling removes the program folder **including its data folder** (the disc copy can be made again from your own
image). Your settings, saves and replays in `%APPDATA%\GT4Recomp` are kept, unless you tick the box, which deletes them
only for the Windows user running the uninstall.

## Known issues

- Every known issue of 1.2.0 is still open (the game is unchanged: same game build and the same gt4-gs 1.2.0).
- The update from 1.2.0 hands the new setup to Windows Explorer, which shows the administrator prompt. If the prompt is
  declined or does not appear, run the setup yourself.
- When a different administrator account approves the setup, the old per-user files of the player are removed by the
  launcher at its first start instead of by the setup.
- An update started through Windows Explorer (the fallback when the elevated start fails) shows the setup pages.
