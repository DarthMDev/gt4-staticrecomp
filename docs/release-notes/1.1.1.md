# GT4Recomp 1.1.1 (draft)

**Progressive 480p menus.** After your first race, the menus, the garage and the loading screens are shown at full
480p like the races, instead of the original interlaced 480i. You need your own disc image of the game.

## Install or update

- New install: download **GT4Recomp-Setup-1.1.1.exe** and run it (per-user, no administrator rights).
- Update from 1.1.0: accept the update in the launcher, or run the new installer over the old one. Settings, saves,
  replays and the copy of your disc image are kept; settings get the new row automatically (a backup is made first).
- Update from 1.0.0: run the installer (the 1.0.0 launcher cannot install updates by itself).

## What's new

- **Progressive 480p menus and races.** Menus get twice the lines (448 instead of 224), so text and car pictures are
  sharper, especially when the picture is upscaled. Menus and races now use the same video mode, so going from a menu
  into a race (and back) no longer blanks the screen for a second. The menus you see right after starting the game
  are still 480i: the switch to 480p happens once, at the start of your first race.
- **Settings > Graphics > Progressive 480p**, on by default. Turn it off for the original interlaced 480i menus.
- The game's own Screen option (480i / 480p) no longer matters while Progressive 480p is on: both give 480p.

## Known issues

- Menus use the same 16-bit colour as the races (the mode the game's own 480p uses), so some gradients may show a
  little banding. Tell us if a screen looks worse than before.
- The boot logos and the menus before the first race, photo mode, the photo development screen and the movies still
  use the game's interlaced modes; going in and out of them still blanks the screen briefly. They come in a later
  update.
- Split screen and photo mode have had little testing at ultrawide ratios (they stay 16:9, pillarboxed).
- Some license demos and menu backgrounds do not play (the same as PCSX2 with default settings).
- Racing wheels are not supported yet.
- The installer and the launcher are not code-signed, so Windows SmartScreen may warn on the first start ("More info",
  then "Run anyway").

## Requirements

Unchanged: Windows 10 or 11 64-bit, a processor with SSE4.1, a graphics card with Vulkan 1.2, your own Gran Turismo 4
USA v2.00 (SCUS-97328) disc image as a plain .iso, and about 6 GB free.
