# GT4Recomp 1.0.0

The first stable release: **Gran Turismo 4 (USA, SCUS-97328 v2.00) recompiled to run natively on Windows**, with a launcher and a one-click installer. You need your own disc image of the game.

## Install

- Download **GT4Recomp-Setup-1.0.0.exe** and run it. It installs for your Windows user only (no administrator rights) into %LOCALAPPDATA%\Programs\GT4Recomp.
- If the Microsoft Edge WebView2 Runtime is missing (rare on Windows 10, built into Windows 11), the installer downloads it from Microsoft.
- Start **Gran Turismo 4** from the Start menu. On the first start the launcher asks for your disc image (.iso), copies it, checks it and downloads the PCSX2 GS renderer (gt4-gs 1.0.1). Then press **Play**.

## Requirements

- Windows 10 or 11, 64-bit.
- A processor with **AVX2** (Intel 4th gen Core / AMD Ryzen or newer). The launcher checks it.
- A graphics card with **Vulkan 1.2** and current drivers. The launcher checks it and names the driver update when Vulkan is missing.
- Your own disc image of **Gran Turismo 4 USA v2.00 (SCUS-97328)** as a plain .iso.
- About **6 GB** free: 5.3 GB for the copy of your disc image plus the program.

## What's new

- **Launcher**: setup from your disc image (copy, check, game files), Play, settings (graphics, display, advanced), a save and replay library with import, controller remapping, a tray icon while you play, and update checks that never install anything without asking.
- **Renderers**: the **PCSX2 GS** in its own process (gt4-gs 1.0.1, downloaded by the launcher, internal resolution from 480p to 8K, FXAA) and **CoreGS 1.1** built in as the fallback when the PCSX2 GS is missing or fails.
- **Controllers through SDL3**: Xbox, DualShock 4, DualSense, Switch Pro and other pads work out of the box, mapped to the DualShock 2 layout with analog L2/R2 pressure. Remap them in the launcher.
- **Keyboard layout**: W or Enter accelerate and confirm, S brake, Space handbrake, A/D and the arrows steer, Backspace or Esc back, Shift nitro, R and F gear up and down, Q look back, C or Tab camera, P Start. Alt+Enter or F11 switch fullscreen.
- **16:9 and 480p by default**: the game boots in widescreen (launcher setting "Widescreen 16:9") and races run in 480p progressive.
- **License tests are playable**. Some license demos and menu backgrounds are skipped, as in PCSX2 with default settings.
- **RivaTuner / MSI Afterburner overlay** works with the PCSX2 GS (Arbitrary Code Guard is off by default; it can be turned on in Advanced).
- **Crash-safe memory card**: saves survive a crash or a forced close.
- **60 FPS at 100% game speed** in every scene we test (Ryzen 7 5700X, Radeon RX 9060 XT).

## Known issues

- Some license demos and menu backgrounds do not play (the same as PCSX2 with default settings).
- Racing wheels are not supported yet.
- Ultrawide and other screen ratios are not supported yet: the game shows 16:9 (planned after 1.0.0).
- The installer and the launcher are not code-signed, so Windows SmartScreen may warn on the first start ("More info", then "Run anyway").
- Long sessions and GPUs other than AMD have had less testing; please report problems with the launcher log (Settings > About > Open log folder).
