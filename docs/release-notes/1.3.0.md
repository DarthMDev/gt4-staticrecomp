# GT4Recomp 1.3.0

**Gran Turismo 4 and Gran Turismo 4 Spec II side by side, a multi-game launcher, and a launcher you can carry.**
You need your own disc image: Gran Turismo 4 (USA, v2.00) for the original game, and your own Spec II 1.10 image for
the mod. GT4Recomp ships no game files, no disc images and no Spec II files.

## Install or update

- Update from 1.2.x: accept the update in the launcher and say yes to the one administrator prompt. The update is
  silent, and the launcher starts again by itself when it is done. Your settings, saves and replays are kept: they
  stay in `%APPDATA%\GT4Recomp`, and the first start moves each game's files into its own `games\gt4` or `games\spec2`
  folder.
- New install: download **GT4Recomp-Setup-1.3.0.exe** and run it. The setup ships both game executables
  (`gt4vulkan.exe` and `gt4vulkan-spec2.exe`), the runtime files, the shaders and the licences.
- Portable: download **GT4Recomp-1.3.0-portable.zip**, unpack it anywhere and run `GT4Recomp.exe`. The portable build
  keeps its settings in `user\` and its large data in `data\` beside the executable, uses no registry or system
  folders, and updates by swapping the zip contents.
- Standalone game: the installed `gt4vulkan.exe` (Gran Turismo 4) and `gt4vulkan-spec2.exe` (Spec II) can be started
  directly, without the launcher. They find the installed game from their own folder, read the launcher's settings
  (`game.ini`, `gt4-gs.ini`) and use the same prepared files, cards and saves.

## New

- **Gran Turismo 4 Spec II 1.10 as a second game.** The launcher identifies the Spec II disc by its executable
  (SCUS-97436), prepares the derived ELF from your own image (the 35 injector words and the data-segment split are
  applied ahead of translation) and starts `gt4vulkan-spec2.exe`. Same-executable variants are accepted, such as the
  Brazilian Portuguese translation, which only replaces language data. Any other SCUS-97436 program, including the
  unmodified GT4 Online Public Beta, is refused with a clear message because it needs its own patch map.
- **Each game has its own files.** Disc copy, prepared files, runtime card, save library and replays live under
  `games\gt4` and `games\spec2`; settings, controls, GSdx and textures are shared. The home screen has a game
  selector with each game's logo and its own Play/Install action, and the game you played last is selected at start.
- **What's new.** The home screen shows the release notes of the installed version, and can show the new version's
  notes when an update is available.
- **Automatic language.** The launcher follows the Windows display language and speaks English (en-US) and Brazilian
  Portuguese (pt-BR); General > Language overrides it. All launcher text, messages, settings, the About page and these
  notes are translated. The translation guide is [docs/TRANSLATING.md](../TRANSLATING.md).
- **Graphics API choice (GSdx).** Settings > Graphics > **Graphics API** writes `[EmuCore/GS] Renderer`:
  **Vulkan** (recommended, default), **Direct3D 12** (recommended) and **Direct3D 11** (for older PCs). OpenGL comes
  later: it needs an allow-list entry in a new gt4-gs release.
- **Portable build** (TASK-098): the same launcher as a zip that runs from any folder, with its own `user\` and
  `data\` folders and no registry or system folders.
- **Standalone game executable** (TASK-097): both game executables start on their own with the defaults built in
  (GSdx, 480p, 16:9 hold, automatic ultrawide, fullscreen, vsync) and the launcher's settings, so a double-click works
  and a missing piece shows a native message instead of a silent exit.

## Changes

- **Game builds.** Both targets are built from one release recipe: the v2.00 game (`gt4vulkan.exe`, slice279) and the
  Spec II game (`gt4vulkan-spec2.exe`, slice280), with the target-aware hooks for the 16:9 hold, the 480p race display,
  the camera/HUD aspect and the license demo guard. The installer ships both executables; the launcher downloads
  gt4-gs 1.2.1.
- **The v2.00 game is frame-identical to 1.2.3.** Headless menus, day race and night race runs against the 1.2.3 build
  give the same frame-dump lists and the same GS stream hashes (measured; see [BUILD.md](../BUILD.md)).
- **Spec II license demo guard.** Spec II demos that our FPU cannot decrypt bit-exactly are skipped instead of
  crashing the game: 142 of the 256 demos on the disc are protected this way, and the rest play normally. The guard
  logs one line per skipped demo (`[license-guard]`).
- **The launcher's Spec II preparation reproduces the release tooling.** The Rust setup derives the same ELF as
  `scripts/spec2_elf_patch.py` (pinned SHA-256 `36f60b1a…`) from the same image; a test compares the two byte for byte
  when the owner's image is present.
- **One settings set for both games.** The launcher keeps one settings and controls set, one GSdx configuration and
  one `Textures` folder; only the executable, the disc image, the prepared files and the save folder differ per game.

## Fixes

- **Spec II's Options menu closed the game.** Opening Options stopped with `missing code at 0x003CA690`. The callback
  is built in the Options page by two instructions 53 apart, and the translator only paired instructions up to three
  apart, so that function was never compiled. The Spec II translation now seeds that whole class of entries (wide
  `lui`/`addiu` pairs, stack-frame fallthrough entries and literal pointers inside executable segments): +47,077
  instructions and 1,517 functions, and Options and its submenus open normally. The owner test passed on the fix.
- **The first-start migration test was flaky.** The launcher test that moves a 1.2.x install into `games\gt4` failed
  four times and passed six when run repeatedly. A scanner or the Windows indexer can hold a freshly written file for
  a few milliseconds, and the rename then fails with a sharing violation instead of moving the folder. The move now
  retries that transient error five times (20-100 ms apart) before reporting a real failure, so a scan no longer delays
  the update; the test still checks that the files really moved.

## Known issues

- CoreGS 2.0 is still in development and is not offered; GSdx is the renderer.
- OpenGL is not offered yet (it needs a new gt4-gs release).
- Direct3D 12 and Direct3D 11 are new options. Vulkan is the tested default; use Direct3D 11 only on PCs where Vulkan
  is not available.
- GT mode in Spec II needs game data created in-game, like v2.00; the first start offers the creation flow.
- The Spec II logo on the home screen is a placeholder (the GT4 logo with a "Spec II" line) until the authors' logo is
  added.
- Every known issue of 1.2.3 is still open.

## Requirements

- Windows 10 or 11, 64-bit.
- A Vulkan-capable GPU for the default renderer (Direct3D 12 or 11 as alternatives). The PCSX2 GS (`gt4-gs.exe`) runs
  in its own process and is downloaded by the launcher (GPL-3.0-or-later, source in its release).
- Your own Gran Turismo 4 (USA, v2.00) disc image for the original game, and your own Gran Turismo 4 Spec II 1.10
  disc image for the mod.
- Disk space: a copy of your disc image (about 5.2 GB for the v2.00 image; the Spec II image is about 3.7 GB) plus the
  prepared files, for each game you install.
