# GT4Recomp 1.2.2

**A lighter game on the CPU, with the same picture.** You need your own disc image of the game.

## Install or update

- Update from 1.2.1: accept the update in the launcher and say yes to the one administrator prompt. The update is
  silent, and the launcher starts again by itself when it is done.
- Update from 1.2.0 or 1.1.0: accept the update in the launcher. Windows shows the administrator prompt; say yes. If
  nothing happens after the download, close the launcher and run **GT4Recomp-Setup-1.2.2.exe** yourself. The first
  start moves your files to the 1.2.1 layout (see the [1.2.1 notes](1.2.1.md)).
- Update from 1.0.0: run the installer (the 1.0.0 update button does not work).
- New install: download **GT4Recomp-Setup-1.2.2.exe** and run it.

## Performance

The game spends less time per frame on the CPU. The work sent to the vector unit (VU1) and to the graphics process is
batched instead of handed over piece by piece, so the threads wait for each other far less:

- VU1 jobs per frame dropped from thousands to a few dozen (36 in the showroom, 59 on the Nordschleife, 80 in a night
  race with five cars).
- Night race, the heaviest scene: the game's CPU work per frame went from 11.8 to 10.0 ms out of the 16.7 ms a frame
  lasts at 60 FPS, so slower CPUs have about 2 ms more headroom.
- Owner test on a Ryzen 7 5700X: 60 FPS with no late frame and no audio dropout in the showroom, a Nordschleife time
  trial and a night race.

The picture is unchanged: menus, a day race and a night race give frames identical to 1.2.0, bit for bit.

## Unchanged

- The launcher is the 1.2.1 launcher, with only the version number changed.
- GSdx (gt4-gs) stays at 1.2.0.
- Settings, controls, saves and replays are kept.

## Known issues

- Every known issue of 1.2.1 is still open.
- In a night race, the flares still make the game wait for the graphics process (about 1.3 ms per frame). Settings >
  Graphics > Performance Mode skips them on weaker PCs.
