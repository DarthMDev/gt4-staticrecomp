## Controls page v2: DS2 hero, live input, real mapping (TASK-019)

- Owner request: the Controls page looked generic. Rebuilt around GT4Recomp's own DualShock 2 drawing
  (`ui/js/controller-svg.js`): two mirrored cubic halves for the silhouette, recessed dishes, D-pad arms, the four face
  buttons with stroke symbols, L1/L2/R1/R2 behind the body, two sticks in collared wells, Select bar, Start triangle,
  mode button and LED. No Sony artwork, photos, logos or marks; classes and SVG attributes only (CSP).
- Chips with short leader lines show the XInput control (Controller view) or the key (Keyboard view) beside every DS2
  button; changed buttons have an amber edge; a compact legend explains the XInput glyphs.
- Live input (`ui/js/controls-model.js`, pure): the first connected pad (the one the game reads) and the keyboard light
  the DS2 buttons through the current bindings, so a swap shows where the game would see the press. L2/R2 fill with the
  trigger value; the panel meters show the pressure the game computes (deadzone and curve, the `native/controls.cpp`
  formula). Sticks move in their wells; panel scopes show the per-axis deadzone. Status pill: pad name, Connected / No
  controller, "controller 1 of 2" with two pads. Animation frames plus a 100 ms timer (headless runs have no frames).
- Mapping: A (or a second click/tap) opens a rebind sheet with a 5 s countdown; pad presses come from `capture_binding`
  (XInput), keys from the page; B and Esc cancel, so B moves only through a swap. A conflict opens Swap/Move or Cancel.
  Y resets the button, X resets everything after a confirmation. Trigger deadzone and curve, and new stick deadzones,
  are panel rows. Every change writes `controls.toml` at once; refused changes keep the old file.
- Rust: `gt4controls` gains `assign` (family replace, swap, refusal without swap, trigger options kept), `holder_of`,
  `reset_all`, `is_default`, `stick_deadzone`/`set_stick_deadzone` (XInput default deadzones). `capture_binding` now
  only detects (`{control, source}`); new commands `assign_binding` and `reset_all_bindings` (commands.list, main.rs,
  capabilities); `get_controls` returns sources, `xinput`, `key`, `is_default`, the analog rows and `locked`; stick rows
  `lstick_deadzone`/`rstick_deadzone` in `set_setting`; the trigger deadzone default now reads 11.8 % (was 0).
  Controls writes go through `change_controls` (copy, write, then keep).
- The old page used drawing ids (`up`, `analog`) that did not match the backend ids (`dpad_up`): fixed by using the
  controls file ids everywhere.
- Tests: `cargo test --workspace` 204 passed, 0 failed, 3 ignored (gt4controls 16 + docs 4; gt4l-tauri 34, flow audit
  covers swap, stick deadzone and reset all on the written file). nav-test 140 of 140; focus-check 90 of 90 (headless
  Edge). Real exe (scratch data folder, WebView2 remote debugging): 23 probed commands, 0 ACL denials; the Controls tab
  renders with no CSP violation.
