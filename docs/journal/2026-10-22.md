  what make this project possible."). README now names the external renderer GSdx and CoreGS 2.0 "in development".

## CoreGS 3.0 in scope (owner decision)

- The render pipeline is modernised in stages: CoreGS 2.0 optimises inside VU1 + GS; CoreGS 3.0 (TASK-090) moves the
  VU1 work onto the GPU and renders natively, opt-in, with fidelity as a measured target and effects restored one by
  one. A faithful renderer stays the default; game logic never changes. AGENTS.md scope updated (a native renderer
  was out of scope before); COREGS2-ROADMAP gains the CoreGS 3.0 section and the launcher gate for CoreGS 2.0.

## Roadmap phases (owner decision)

- Phase 1 (Windows PC, 1.x) is done (base of 1.0.0). Phase 2 (current) is CoreGS 2.0, released as GT4Recomp 2.0.0 with
  CoreGS 2.0 as the default renderer and GSdx as the fallback. Phase 3 is native Linux, phase 4 Android, both after
  2.0.0 and both on CoreGS 2.0. The ARMSX2 GS pipeline is no longer the mobile plan (README roadmap, credits row removed;
  AGENTS.md phases updated).
